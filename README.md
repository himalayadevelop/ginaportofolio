A complete, production-ready portfolio application for **Gina Pasa** – focusing on Information Technology, Digital Communications, and Education. Built with a bespoke editorial aesthetic, smooth interactions, and bilingual support (Bahasa Indonesia & English).

---

## 🌟 Highlights

- **Profil & Narasi Profesional**: Menghubungkan ketertarikan pada teknologi informasi, komunikasi, pemanfaatan media digital, dan semangat pembelajaran berkelanjutan.
- **Bilingual Context Switching (ID / EN)**: Dukungan penuh Bahasa Indonesia dan English untuk navigasi, deskripsi keahlian, dan narasi profil.
- **Glassmorphism Navigation with Scroll Spy**: Header dengan dynamic blur backdrop dan active section pill (*Beranda*, *Tentang*, *Keahlian*, *Kontak*).
- **Hero Editorial Minimalis**: Tipografi serif prestisius (*Instrument Serif*), metrik terukur, dan kartu ringkasan eksekutif.
- **Bidang Kompetensi & Keahlian**: Tiga pilar utama (*Teknologi Informasi & Rekayasa Perangkat Lunak*, *Komunikasi Digital & Media*, serta *Pendidikan & Kemampuan Beradaptasi*).
- **Formulir Kontak Tervalidasi**: Validasi input instan, jam waktu nyata Jakarta (WIB, UTC+7), dan tombol WhatsApp langsung.
- **Digital Resume Modal**: Tampilan ringkasan CV satu halaman dengan fitur unduh dan cetak.

## 🚀 Menjalankan Aplikasi

```bash
cd d:\webprofil

# Menjalankan development server
npm run dev

# Membangun versi produksi (Build)
npm run build

# Meninjau versi produksi (Preview)
npm run preview

# Memeriksa kualitas kode (Linting)
npm run lint
```
